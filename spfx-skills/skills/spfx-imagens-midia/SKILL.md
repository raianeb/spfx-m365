# Imagens e mídia

## Quando usar
Ao exibir imagens, vídeos ou ícones em web parts.

## Regras-base
- Imagens responsivas, com tamanho adequado à área de exibição.
- Carregamento preguiçoso para imagens fora da tela.
- Texto alternativo em toda imagem informativa; imagem decorativa sem texto alternativo.
