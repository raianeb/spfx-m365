# CSS e estilos

## Quando usar
Ao criar ou alterar arquivos de estilo de uma web part ou extensão.

## Regras-base
- Use SCSS com módulo (`.module.scss`) para escopo local.
- Nomes de classe descritivos e consistentes.
- Não altere estilos globais do host page.
- Evite seletores muito profundos e dependência de estrutura de terceiros.
