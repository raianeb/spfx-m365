# Glassmorphism (opcional)

## Quando usar
Somente quando o projeto pedir explicitamente o estilo visual em vidro.

## Regras-base
- Tokens compartilhados para fundo, blur, borda e sombra.
- Garanta contraste de texto sobre o fundo translúcido.
- Ofereça alternativa sem blur quando o navegador ou o tema não suportar.
