# wp-hub-aprendizagem

Web part **Hub de Aprendizagem** da Equipe M365: jornadas de treinamento por área (vídeos do YouTube, vídeos da biblioteca, documentos e links), com progresso individual, acompanhamento por gestor, estúdio com aprovação e administração das áreas.

- Escopo aprovado: `../hub-aprendizagem/escopo.md`
- Definição de dados: `../hub-aprendizagem/definicao.json`
- Provisionamento: `provisionamento/INSTRUCOES.md`

## Compilar

```bash
npm install
npm run build
```

O pacote é gerado em `sharepoint/solution/wp-hub-aprendizagem.sppkg` (não versionado).
